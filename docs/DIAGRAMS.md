# PlaceGraph diagrams

| File | What it shows | Best time to show it |
|---|---|---|
| `er_diagram.pdf` / `.svg` / `.png` | Chen-notation ER diagram: entities, weak entity (double box), identifying relationship (double diamond), attributes, keys, cardinalities. | When asked for the ER diagram. |
| `relational_schema.pdf` / `.svg` / `.png` | Physical MySQL schema: 12 tables, types, PK/FK/UNIQUE, foreign-key arrows, the weak entity and `users`. | When explaining implementation and integrity. |

The SVG files are vector artwork and stay sharp in Word, PowerPoint or PDF. They are generated by `npm run diagrams` (`scripts/gen-diagrams.mjs`), which also renders the PDF and PNG versions with the installed Edge/Chrome. After a schema change, edit the generator and re-run it.

Open on Windows: `Start-Process .\docs\er_diagram.svg`.
